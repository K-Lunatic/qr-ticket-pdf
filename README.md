# 행사 QR 카드 PDF

이름과 링크를 여러 개 입력하면 참가자별 QR 카드를 만들고, 가로 A4 한 장에 세 장씩 배치한 PDF를 내려받을 수 있습니다. 행사에서 링크를 종이로 배포하는 작업을 줄이려고 만든 브라우저 도구입니다.

```sh
npm ci
npm run dev
```

기본 예시로 PDF를 만들고 QR을 스캔하면 `example.com`이 열립니다. 카드와 PDF는 브라우저에서 생성하며, 별도 서버를 사용하지 않습니다. 정적 빌드는 `npm run build`로 생성합니다.

최초 구현은 2026년 6월입니다. 공개본은 예제 입력과 자체 제작한 중립 카드 도안을 사용합니다.
